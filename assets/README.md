# Images à déposer ici

Déposez les fichiers dans ce dossier **en gardant exactement ces noms** (tout en
minuscules, extension `.jpg`). Tant qu'une image manque, son emplacement reste
visible avec son libellé — rien ne casse.

Toutes les images sont affichées en `object-fit: cover` : elles remplissent leur
cadre et sont recadrées au centre. Prévoyez donc le sujet au centre, sauf mention
contraire.
